# Road to School
https://my7337.itch.io/road-to-school
간단한 조작으로 할 수 있는 달리기형 게임입니다.

## 특징

- **싱글톤 패턴**
- **Input System**
- **맵 무작위 생성**
- **JSON을 이용한 직렬화**

## 조작법
- 이동/점프/구르기: **WASD**
- 클릭: **마우스 이동 및 좌클릭**

## 프로젝트 구조
```
Assets/
├─ 01. Scenes/            # 게임 씬(시작, 메인, 플레이, 커스터마이징)
├─ 02. Scripts/           # 스크립트
│  ├─ Achievement          # 도전과제 스크립트
│  ├─ Audio                # 오디오 관련 스크립트
│  ├─ Camera               # 카메라 이동 관련 스크립트
│  ├─ ColorPicker          # 커스터마이징 컬러 피커 관련 스크립트
│  ├─ Data                 # 플레이어 데이터 관리 스크립트
│  ├─ Manager              # 게임 전체를 관리하는 매니저
│  ├─ Obstacle             # 장애물 관련 스크립트
│  ├─ Player               # 플레이어 이동 
│  ├─ PowerUps             # 무적, 속도증가 등 파워업 관련 스크립트
│  └─ UI                   # UI 관련 스크립트
├─ 03. Prefabs            # 재사용 가능한 오브젝트
├─ 04. Animations         # 플레이어 및 장애물 애니메이션
├─ 05. Audios             # 오디오 클립
├─ 06. Inputs             # 플레이어 인풋 시스템
├─ 07. Maps               # 맵
└─ 10. ScriptableObjects  # 게임 데이터(업적, 파워업 아이템)
```

## 핵심 시스템

### 제네릭 싱글톤 패턴
-어디서든 쉽게 호출하기 위해서 싱글톤 패턴을 사용하였습니다. 간편한 싱글톤 패턴 사용을 위해서 제네릭 싱글톤을 사용하였습니다

### JSON 파일 직렬화
-JSON 파일을 이용한 직렬화로 데이터 관리를 효율적이게 관리할 수 있습니다

### 맵 재생성 방식
- 프리펩에 있는 맵을 미리 생성해놓고, 맵을 재사용 하는 방식으로 새로운 맵을 생성합니다. 이를 통해 메모리 관리가 용이합니다

### 맵 무작위 생성 방식
-프리펩을 이용해 몇가지 맵을 만들어 놓고 무작위로 생성이 됩니다


## 트러블 슈팅

### 1. 라인 이동 시 스냅 현상 발생

-    **발단:** 플레이어가 라인 이동시 스냅하는 현상이 발생해서 부드럽게 이동하는 기능을 만들려고 했습니다

-    **해결과정:** Mathf.Lerp(start, end, t)를 이용해서 값을 start에서 end로 서서히 증가시키려고 했습니다. 하지만 한 프레임 밖에 이동하지 않는 현상이 발생했습니다 t값을 루프가 돌 때 마다 증가시키는 코드를 추가해서 해결했습니다

-    **결과:** 캐릭터가 스냅하지 않고 부드럽게 이동하게 되었습니다

### 2. Git 병합시 오류 발생

-    **발단:** 개인 branch 에 develop branch 의 최신 커밋을 병합하는 과정에서 문제가 발생하였습니다. 지면 역할을 담당하는 프리팹 파일이 정상적으로 병합되지 않아, 게임 실행 직후 플레이어가 지면 없이 곧바로 낙하하는 현상이 나타났습니다

-    **해결과정:** 문제 해결을 위해 팀원이 별도의 branch 를 새로 생성하여 해당 branch 에서 병합을 시도하고 실행 테스트를 진행하였습니다. 또한, 프로젝트 폴더를 삭제한 뒤 저장소를 다시 클론하여 환경을 재구성하는 방법도 병행하였습니다.

-    **결과:** 여러 차례 다른 branch 에서 병합을 시도하고, 히스토리 탭에서 문제가 없다고 판단되는 커밋을 적용해 보았으나 문제가 지속되었습니다. 그러나 최종적으로 로컬 프로젝트를 삭제하고 저장소를 새로 클로닝하자 누락되었던 프리팹 파일이 복원되면서 문제가 완전히 해결되었습니다.

- ### 3. 오디오 관련 스크립트 가독성 문제

-    **발단:** BGM과 SFX를 실행 시켜주기 위해서 오브젝트에 맞는 오디오 소스를 넣어서 실행을 했지만, 코드의 가독성이 좋지 않다는 생각이 들었습니다

-    **해결과정:** 모든 BGM과 SFX를 AudioManager.cs에 배열을 생성한 뒤, Inspector 창에서 오디오 소스들을 달아줬습니다. 그리고 이후 BGM과 SFX가 필요한 부분에서 AudioManager에 있는 Play메서드를 호출하여 인덱스 안에 있는 오디오를 송출하게 하였습니다

-    **결과:** AudioManager.Instance.PlaySFX(index) AudioManager.Instance.PlayBGM(index)을 기능을 분리하고 가독성이 좋게 되었습니다

### 4. 장애물의 회전값 미적용 현상 발생

-    **발단:** 맵 제작중 장애물 프리펩 중 하나가 회전값이 적용되자 않는 현상이 발생했습니다

-    **해결과정:** 해당 프리펩에 애니메이션과 회전값이 같이 들어가있는 것을 발견해서, 회전값을 따로 분리할 부모 오브젝트를 생성했습니다
  
-    **결과:** 장애물이 정상적으로 회전하게 되었습니다
  
### 5. 업적 데이터 저장 방법 고민

-    **발단:**  업적을 만들어 id와 bool값을 이용하여 클리어 여부를 저장하려고 했습니다.

-    **해결과정:**  Json 파일을 이용하여 업적의 내용과 클리어 여부를 전부 저장하려고 했지만, ScriptableObject를 이용하면 더 쉽게 업적을 만들고 저장할 수 있다는 정보를 알게되어서 ScriptableObject를 사용하는 방식으로 변경했습니다

-    **결과:**   스크랩터블 오브젝트를 이용하여 업적의 내용(업적 이름,  목표 등)을 살펴보고, JSON 파일의 id를 통해 어떤 업적인지 식별하고 bool 값인 isClear를 통해 이미 깬건지 아닌지를 판단하도록 만들었습니다.
